• Apache ShenYu - AI网关插件

    插件介绍： Apache ShenYu 是一款高性能、异步响应式、可扩展的 API 网关。 AI 插件生态提供统一的大语言模型（LLM）接入能力， 支持 Prompt 提示词管理、请求与响应转换、Token 用量管理及模型代理， 帮助业务系统通过统一网关接入不同的 AI 模型服务。

    项目亮点及技术贡献：

    • AI 模型统一接入： 基于 AiProxy 插件实现大语言模型统一代理接入， 通过 Selector、Rule 动态配置模型服务提供商、请求地址、 模型名称及 API Key，屏蔽不同模型服务商之间的接口差异， 降低业务系统对单一 AI 服务商的依赖。
    • Prompt 提示词动态注入： 基于 AiPrompt 插件实现请求提示词增强能力， 支持在原始消息前后动态追加 Prompt 内容， 通过 preRole、postRole 配置消息角色， 将系统提示词、上下文指令等统一管理在网关层， 无需修改业务系统即可实现提示词策略调整。
    • AI 请求动态转换： 基于 AiRequestTransformer 插件实现请求转换能力， 支持通过配置规则对 HTTP 请求头、请求路径、查询参数、 JSON 请求体及表单数据进行转换， 解决不同 AI 模型接口之间的请求格式差异， 提高不同模型服务之间的兼容性。
    • AI 响应内容转换： 基于 AiResponseTransformer 插件实现上游响应内容转换， 根据配置的提示词和转换规则对响应数据进行处理， 支持响应结构适配、内容整理及不同客户端数据格式转换， 降低业务端对不同模型响应格式的适配成本。
    • Token 用量统计与限流： 基于 AiTokenLimiter 插件实现 AI 请求 Token 使用量限制， 结合 Redis 实现用量数据管理， 支持配置时间窗口、Token 阈值及请求维度等限流规则， 超出限制时通过 HTTP 429 返回限流响应， 帮助企业控制模型调用频率及 AI 服务使用成本。
    • 插件化执行链路： 将 AI 能力集成到 ShenYu 现有插件体系中， 利用网关 Selector、Rule 及插件执行机制实现灵活编排， 支持 Prompt 注入、Token 限流、模型代理及请求转换等能力协同工作， 提高 AI 网关功能的可扩展性和灵活性。
    • API Key 统一管理： 通过网关代理方式管理客户端与上游模型服务之间的 API Key， 将真实模型服务凭证保留在网关侧， 避免上游服务密钥直接暴露给客户端， 提升 AI 服务接入过程中的凭证管理能力。
