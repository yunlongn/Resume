• Apache ShenYu - 高性能 API 网关

    项目介绍： Apache ShenYu 是一款基于 Java 的高性能、异步响应式 API 网关， 提供服务代理、协议转换、流量治理及插件化扩展能力。 参与 Apache ShenYu 开源项目开发，涉及网关插件扩展、 服务注册发现、配置数据同步及核心模块重构。

    技术栈： Java、Spring Boot、Spring WebFlux、Reactor、Redis、 Dubbo、gRPC、Zookeeper、Etcd、Consul、Eureka、 SPI、Maven。

    核心贡献：

      ➢ AI 网关建设： 参与 Apache ShenYu AI 网关能力建设，围绕大模型统一接入与代理转发，完善 AI Proxy 相关能力，支持多模型服务接入及统一网关管理。

      ➢ AI Token 管理： 参与 Token 用量统计与计算、Token 限流及用量管理能力建设，实现 AI 请求用量管控，为大模型 API 资源管理和成本控制提供支持。

    • 网关插件开发： 参与 Signature 签名插件扩展、腾讯云 CLS 日志插件开发， 以及 Logging、Sentinel、Hystrix、Response Writer 等插件优化与问题修复。
    • 流量治理： 参与 Divide 插件灰度发布能力完善， 修复 RateLimiter 限流插件并发处理问题， 涉及 Token Bucket 并发测试及流量控制机制。
    • 服务注册与发现： 参与 Discovery、Spring Cloud 插件重构， 优化 Zookeeper、Etcd、Consul 等注册中心的数据同步机制， 修复 Eureka 实例查询及多 Selector 对接不同注册中心的问题。
    • 配置同步与元数据管理： 参与 Admin 数据监听、注册实例持久化及同步逻辑重构， 处理 Selector、Rule、Metadata 缓存及数据一致性问题。
    • 协议与客户端扩展： 参与 Dubbo、gRPC、Tars 等模块优化， 参与 Java SDK、OpenFeign 集成及 WebClient 插件重构， 完善网关客户端接入与响应处理能力。
